# 智能财富管理运营平台｜静态 UI Demo

本项目是比赛方案的第一阶段前端演示，用于确认产品结构、页面布局和核心操作流程。目前仅包含静态页面及前端交互，不依赖后端、数据库或算法服务。

本目录位于赛事提交包 `touchCIB/frontend`。后续接入阶段，前端通过 Flask HTTP API 获取业务数据，不直接连接 MySQL，也不直接读取 `src/data/raw/` 中的比赛原始文件。

## 一、环境要求

- Node.js 22.13 或更高版本
- npm 10 或更高版本
- 推荐使用 Chrome、Edge 或 Safari 的较新版本

可先检查本机环境：

```bash
node -v
npm -v
```

## 二、本地启动

进入前端项目目录：

```bash
cd /Users/lizhengquan.18/Desktop/兴业/touchCIB/frontend
```

首次运行时安装依赖：

```bash
npm install
```

启动本地开发服务：

```bash
npm run dev
```

启动成功后，在浏览器访问：

```text
http://localhost:3000
```

如果 3000 端口已被占用，请以终端输出的 `Local` 地址为准。

停止服务时，在启动服务的终端中按 `Control + C`。

## 三、构建检查

提交或演示前，可执行以下命令检查项目能否正常构建：

```bash
npm run build
```

构建完成且终端没有报错，即表示静态 Demo 可以正常编译。

## 四、当前 Demo 包含的功能

### 1. 客户画像

- 模拟导入客户 CSV 文件
- 以数据表格概览客户，并支持客户编号、城市、职业、等级和风险偏好的模糊查询
- 支持风险等级、城市筛选，点击客户行后进入单客户档案详情
- 展示客户基础资料、资产概况、风险等级和行为标签
- 展示风险评估结果及客户画像
- 模拟重新生成 AI 客户摘要

### 2. 智能投顾

- 选择压力情景和风险偏好
- 调整最低流动性要求
- 展示资产配置建议、收益与风险指标
- 展示配置约束和资产占比图

### 3. 营销运营

- 模拟导入营销任务或客户批次
- 运行营销策略并展示客户筛选结果
- 展示渠道、触达时机和产品 Top 3 推荐
- 查看单个客户的画像摘要、推荐理由和执行状态

### 4. 经营看板

- 展示客户、投顾和营销关键指标
- 展示客户风险分布、营销漏斗及活动趋势
- 用于比赛答辩时快速呈现平台整体运营情况

## 五、当前版本的数据说明

本版本用于确认产品功能和视觉效果，页面中的数据为前端演示数据：

- “导入 CSV”目前只模拟文件选择和处理状态，不会真正解析或保存文件内容。
- 风险评估、资产配置和营销推荐结果均为预设示例，不是算法实时计算结果。
- AI 客户摘要为前端模拟生成，尚未接入大模型接口。
- 页面刷新后，操作状态会恢复为初始状态。
- 当前不需要启动数据库或后端服务。

后续进入第二阶段后，可将比赛提供的 CSV 数据接入后端，再把三个算法模块的计算结果通过接口返回给前端。

## 八、常见问题

### 页面无法打开

确认运行 `npm run dev` 的终端仍处于启动状态，并使用终端显示的本地访问地址。

### 安装依赖时报错

先确认 Node.js 版本符合要求，然后在项目目录重新执行 `npm install`。

### 页面样式或数据没有更新

先刷新浏览器；如仍未更新，可停止服务后重新执行 `npm run dev`。

### 导入文件后没有读取真实数据

这是当前静态 Demo 的预期行为。真实 CSV 解析、数据库存储和算法计算将在后端设计阶段接入。
