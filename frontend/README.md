# 智能财富管理运营平台｜前端 Demo

本项目是比赛方案的前端演示。客户画像与风险评估模块已接入 Flask + MySQL 真实接口；智能投顾、营销运营和经营看板仍保留演示数据，等待对应接口接入。

本目录位于赛事提交包 `touchCIB/frontend`。前端通过 Flask HTTP API 获取业务数据，不直接连接 MySQL，也不直接读取 `src/data/raw/` 中的比赛原始文件。

## 一、环境要求

- Node.js 22.13 或更高版本
- npm 10 或更高版本
- 推荐使用 Chrome、Edge 或 Safari 的较新版本

可先检查本机环境：

```bash
node -v
npm -v
```

## 二、本地启动

### 1. 启动客户画像后端

在 `touchCIB` 根目录配置并初始化 MySQL，详细步骤参见 `backend/README.md`。完成初始化后运行：

```bash
cd /Users/lizhengquan.18/Desktop/兴业/touchCIB
.venv/bin/python -m backend.run
```

确认健康检查地址可以打开：

```text
http://127.0.0.1:8000/health
```

### 2. 启动前端

进入前端项目目录：

```bash
cd /Users/lizhengquan.18/Desktop/兴业/touchCIB/frontend
```

首次运行时安装依赖：

```bash
npm install
```

启动本地开发服务：

```bash
npm run dev
```

启动成功后，在浏览器访问：

```text
http://localhost:3000
```

前端默认请求 `http://127.0.0.1:8000`。如需修改地址，可复制 `frontend/.env.example` 为 `frontend/.env.local`，再修改 `VITE_API_BASE_URL`。

如果 3000 端口已被占用，请以终端输出的 `Local` 地址为准。

停止服务时，在启动服务的终端中按 `Control + C`。

## 三、构建检查

提交或演示前，可执行以下命令检查项目能否正常构建：

```bash
npm run build
```

构建完成且终端没有报错，即表示静态 Demo 可以正常编译。

## 四、当前 Demo 包含的功能

### 1. 客户画像

- 通过接口分页读取 8,000 位客户
- 支持客户编号、城市和职业的后端模糊查询
- 支持风险等级、客户等级和城市组合筛选
- 新建客户后由后端生成客户编号并自动完成风险评估
- 通过画像接口展示真实基础信息、持仓、资产分布、行为统计和动态标签
- 调用 DeepSeek 生成结构化画像摘要，并按画像概述、需求洞察、服务建议展示和加粗关键词
- 提供接口加载、空数据、断连和服务错误状态

### 2. 智能投顾

- 选择压力情景和风险偏好
- 调整最低流动性要求
- 展示资产配置建议、收益与风险指标
- 展示配置约束和资产占比图

### 3. 营销运营

- 模拟导入营销任务或客户批次
- 运行营销策略并展示客户筛选结果
- 展示渠道、触达时机和产品 Top 3 推荐
- 查看单个客户的画像摘要、推荐理由和执行状态

### 4. 经营看板

- 展示客户、投顾和营销关键指标
- 展示客户风险分布、营销漏斗及活动趋势
- 用于比赛答辩时快速呈现平台整体运营情况

## 五、当前版本的数据说明

当前数据来源说明：

- 客户画像与风险评估：真实读取 Flask API 和 MySQL。
- 新建客户风险等级：由后端规则计算并保存。
- AI 客户摘要：默认调用后端本地模板模式；可由后端切换为远程模型模式。
- 智能投顾、营销运营和经营看板：仍为前端演示数据。

客户画像接口不可用时，页面会保留框架并显示明确的连接错误，不会回退为伪造客户数据。

## 八、常见问题

### 页面无法打开

确认运行 `npm run dev` 的终端仍处于启动状态，并使用终端显示的本地访问地址。

### 安装依赖时报错

先确认 Node.js 版本符合要求，然后在项目目录重新执行 `npm install`。

### 页面样式或数据没有更新

先刷新浏览器；如仍未更新，可停止服务后重新执行 `npm run dev`。

### 客户列表显示“接口连接失败”

确认 Flask 服务已在 `http://127.0.0.1:8000` 启动，并检查 MySQL 和 `.env` 配置。浏览器使用 `localhost:3000` 或 `127.0.0.1:3000` 访问时，后端已配置相应 CORS 白名单。
